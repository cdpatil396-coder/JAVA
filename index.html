1. Advanced Function Topics

1.1 Anonymous Function Lambda

Definition: An anonymous function is a small function defined without a name using the lambda keyword. It can take any number of arguments, but can only evaluate and return a single expression.

# Syntax: lambda arguments: expression
square = lambda x: x ** 2
print(square(5))  # Output: 25

add = lambda a, b, c: a + b + c
print(add(2, 3, 4))  # Output: 9

1.2 Mapping Functions over Sequences: map

Definition: The map() function applies a specified function to each item of an iterable (such as a list or tuple) and returns a map object (an iterator) containing the results.

# Syntax: map(function, sequence)
numbers = [1, 2, 3, 4, 5]
doubled = list(map(lambda x: x * 2, numbers))
print(doubled)  # Output: [2, 4, 6, 8, 10]

1.3 Functional Programming Tools: filter and reduce

Definition: Higher-order functional tools used to process sequences concisely.

  • filter(function, sequence): Constructs an iterator from sequence elements for which the function returns True.
  • reduce(function, sequence): Imported from functools, applies a function of two arguments cumulatively to sequence items to reduce it to a single value.
# filter example
numbers = [1, 2, 3, 4, 5, 6, 7, 8]
evens = list(filter(lambda x: x % 2 == 0, numbers))
print(evens)  # Output: [2, 4, 6, 8]

# reduce example
from functools import reduce
nums = [1, 2, 3, 4]
product = reduce(lambda x, y: x * y, nums)
print(product)  # Output: 24 (1 * 2 * 3 * 4)

1.4 List Comprehensions Revisited: Mappings

Definition: List comprehensions provide a compact way to construct new lists by applying expressions and optional conditional filters over existing sequences, replacing map() and filter().

nums = [1, 2, 3, 4, 5]

# Replacing map()
squares = [x ** 2 for x in nums]
print(squares)  # Output: [1, 4, 9, 16, 25]

# Combining map() and filter()
even_squares = [x ** 2 for x in nums if x % 2 == 0]
print(even_squares)  # Output: [4, 16]

2. Modules

2.1 Python Program Architecture

Definition: Python program architecture refers to structuring an application into a top-level (main) execution script along with multiple reusable module files containing functions, classes, and variables.

2.2 Module Creation

Definition: A module is created simply by saving Python code inside a file with a .py extension.

# Saved inside 'math_utils.py'
def add(a, b):
    return a + b

def multiply(a, b):
    return a * b

PI = 3.14159

2.3 Module Usage

Definition: A module is used in another Python script by importing it using the import or from ... import statement.

# Saved inside 'main.py'
import math_utils

print(math_utils.add(10, 5))       # Output: 15
print(math_utils.multiply(4, 3))   # Output: 12
print(math_utils.PI)               # Output: 3.14159

2.4 Module Namespaces

Definition: A module namespace is a dictionary mapping containing all global variables, functions, and classes defined within that module. It prevents variable name collisions.

import math_utils

# Accessing module attribute dictionary / names
print(dir(math_utils))
print(math_utils.__name__)  # Output: 'math_utils'

2.5 Reloading Modules

Definition: Imports occur only once per session. To reload a modified module dynamically during execution without restarting Python, use importlib.reload().

import importlib
import math_utils

# Re-executes the module source file code
importlib.reload(math_utils)

2.6 Module Packages

Definition: A package is a directory containing module files along with a special __init__.py file, allowing hierarchical organization using dot notation.

# Directory Structure:
# my_package/
#    ├── __init__.py
#    └── arithmetic.py

from my_package.arithmetic import add
print(add(5, 10))

2.7 Data Hiding in Modules

Definition: Attributes can be hidden from wildcard imports (from module import *) by prefixing them with a single underscore _ or by explicitly setting the __all__ list.

# my_module.py
__all__ = ['public_func']  # Only public_func is exported on wildcard import

def public_func():
    return "Public"

def _hidden_func():
    return "Private/Hidden"

2.8 Enabling Future Language Features

Definition: The __future__ module allows importing features introduced in future Python versions into current code for forward compatibility.

from __future__ import print_function, division

print(5 / 2)  # Output: 2.5 (True division)

2.9 Mixed Usage Modes

Definition: Checking if __name__ == '__main__' allows a file to act as both an imported library module and a standalone executable script.

def calculate(x):
    return x * 10

if __name__ == '__main__':
    # Runs only when executed directly, not when imported
    print("Direct Execution Test:", calculate(5))

2.10 Changing the Module Search Path

Definition: Python searches for modules in directories listed in sys.path. Custom directory paths can be appended at runtime.

import sys
sys.path.append("/custom/path/to/modules")

import my_custom_module

2.11 The import as Extension

Definition: Assigns an alias to an imported module or function to prevent name conflicts or shorten usage.

import math as m
from math import factorial as fact

print(m.pi)    # Output: 3.141592653589793
print(fact(5)) # Output: 120

2.12 Relative Import Syntax

Definition: Used inside package modules to import relative to the current module location using leading dots (. for current folder, .. for parent folder).

# Inside my_package/string_utils.py
from . import arithmetic         # Sibling module import
from ..tools import formatter    # Parent directory module import

2.13 Module Design Concepts

Definition: Core principles for designing clean, scalable Python modules:

Concept Description
High Cohesion A module should focus on a single, well-defined task domain.
Low Coupling Modules should be independent to minimize inter-dependencies.
Avoid Global State Minimize mutating global variables across module boundaries.
Clean Public API Expose only necessary functions using __all__ or _ prefixes.
